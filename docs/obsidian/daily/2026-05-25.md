### Achado P0

QSA oficial, CNPJ Aberto ou Receita confirmam que um socio aparece em um CNPJ. Isso prova `socio -> CNPJ`; nao prova `CNPJ -> grupo`.

Consequencias proibidas para CNPJ lateral:

- nao classificar como `Proprias`;
- nao chamar de `Side business`;
- nao usar como veiculo operacional do grupo;
- nao sustentar tese de enterprise, bioinsumos, verticalizacao ou wedge Senior;
- nao criar aresta `Root -> company` no grafo.
