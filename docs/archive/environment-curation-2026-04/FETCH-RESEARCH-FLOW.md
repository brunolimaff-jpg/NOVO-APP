# Protocolo de Pesquisa Profunda — 🦅 Senior Scout 360

Este protocolo define como agentes devem utilizar o **Fetch MCP** para maximizar a inteligência útil em investigações sobre empresas, especialmente no setor de agronegócio.

## Objetivo
Melhorar a profundidade factual de cada investigação, saindo de simples buscas superficiais para uma análise de evidências reais.

## Ordem de prioridade de páginas

Ao investigar uma empresa, o agente deve priorizar a abertura de links nesta ordem:

1. **Domínio Oficial**: A página inicial para validar identidade e slogam.
2. **Página “Sobre” / Quem Somos**: Essencial para entender o DNA da empresa e fundadores.
3. **Governança / Compliance / Sustentabilidade**: Onde costumam estar dados de certificações e relatórios ESG (vital para Agro).
4. **Produtos / Unidades / Operação**: Onde encontramos o porte real (plantas, fábricas, armazéns).
5. **Carreiras / Trabalhe Conosco**: Indica ritmo de expansão e áreas de dor/contratação.
6. **Notícias Recentes / Sala de Imprensa**: Identifica fatos novos que ainda não estão em buscadores.
7. **Parceiros / Casos de Sucesso / Clientes**: Ajuda no benchmark competitivo.
8. **PDFs Públicos e Relatórios Anuais**: A "mina de ouro" para dados de faturamento e governança.

## Critérios de Relevância

O agente deve "escriturar" as seguintes descobertas ao ler uma página:

- **Porte**: Menção a hectares, cabeças de gado, frota, número de funcionários ou unidades.
- **Expansão**: Novas fábricas, investimentos anunciados, compra de áreas.
- **Operação**: Quais sistemas usam (se mencionado), tipo de culturas produzidas.
- **Tecnologia**: Sinais de modernização ou de processos manuais.
- **Contratação**: Vagas abertas para áreas estratégicas (TI, Comercial, Logística).
- **Risco Regulatório**: Menções a processos ou novas normas do setor.
- **Parceria/Ecossistema**: Quem são os fornecedores de tecnologia atuais.
- **Timing Comercial**: Eventos que justificam uma abordagem agora (fusão, nova safra, crise de gestão).

## Critérios de Descarte

Para economizar custo e tempo, ignore:

- Páginas puramente promocionais sem texto factual útil.
- Diretórios de empresas que apenas listam CNPJ sem info extra.
- Blogs muito antigos ou desatualizados.
- Páginas com boilerplate pesado (termos de uso, cookies) que não agregam ao dossiê.
- Fóruns ou sites de reclamação irrelevantes para B2B.

## Regra de Profundidade

**Qualidade > Quantidade.**
Não abra 20 links rasos. Escolha os 3 a 5 links de maior valor e extraia tudo o que puder deles para montar o Score PORTA.

## Formato de Saída (Dossiê de Fetch)

Cada operação de fetch relevante deve ser sintetizada assim:

- **URL**: [link]
- **Tipo da Página**: (ex: Relatório Anual)
- **Resumo Factual**: [2 parágrafos diretos]
- **Sinais Comerciais**: [bullet points com evidências]
- **Hipóteses de Abordagem**: [Como o vendedor pode usar isso na reunião]

## Regra de Startup

O objetivo não é a perfeição enciclopédica. É **maximizar a inteligência útil com o menor custo operacional**. Se você encontrou a "dor" do cliente no terceiro link, não precisa ler o vigésimo.
