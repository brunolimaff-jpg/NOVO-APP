# Runbooks Operacionais

Estes runbooks orientam resposta a incidentes sem substituir a investigacao por evidencia. Registre horario, SHA do Preview ou producao, escopo afetado e evidencias nao sensiveis.

- [LiteLLM 5xx](./litellm-5xx.md)
- [Indisponibilidade Supabase](./supabase-outage.md)
- [Privacidade Sentry](./sentry-privacy.md)
- [Retencao de dados](./retencao-de-dados.md)

Nenhum runbook autoriza merge, alteracao de env, migration remota ou deploy de producao sem aprovacao explicita.
